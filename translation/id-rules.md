# Indonesian translation rules

- Use casual, natural Indonesian suitable for a personal technical blog. Prefer “kita” over formal constructions when appropriate.
- Preserve the author's meaning, voice, paragraph structure, and level of certainty.
- Keep common software terms in English when Indonesian developers normally use the English term.
- Never translate identifiers, commands, API names, package names, filenames, paths, product names, or acronyms.
- Do not invent explanations, examples, links, or claims that are absent from the source.
- Preserve Markdown punctuation supplied inside each segment.
- Avoid rigid word-for-word translation. The result should sound like it was originally written casually in Indonesian.
