# English translation rules

- Use natural, casual English suitable for a personal technical blog.
- Preserve the author's meaning, personality, jokes, paragraph structure, and level of certainty.
- Keep common software terms, identifiers, commands, API names, package names, filenames, paths, product names, and acronyms unchanged.
- Do not rewrite the article into formal corporate prose and do not add information that is absent from the source.
- Preserve Markdown punctuation supplied inside each segment.
- Translate Indonesian idioms by meaning rather than word-for-word while keeping the original conversational tone.
